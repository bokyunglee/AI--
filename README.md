# 🧠 AI 뉴스 퀴즈 생성기

뉴스 기사 URL만 입력하면 AI가 본문을 분석하여 핵심 키워드를 추출하고, 해당 키워드를 중심으로 교육용 퀴즈를 생성해주는 웹 애플리케이션입니다.

## 🌟 주요 기능
- **정밀 본문 추출**: 주요 뉴스 사이트(네이버, 다음, 에이블뉴스 등)의 광고와 노이즈를 제거하고 순수 기사 본문만 추출합니다.
- **키워드 자동 분석**: 기사 내 언급 빈도가 높은 단어 Top 20을 산출하여 클릭 한 번으로 주제를 선택할 수 있습니다.
- **AI 퀴즈 생성**: **CNU AI API**를 사용하여 본문에 철저히 근거한 사지선다형 문제, 정답, 상세 해설을 생성합니다.
- **실시간 채점 및 피드백**: 제출 즉시 정답 여부를 시각적으로 확인하고, 점수판을 통해 총점을 바로 확인할 수 있습니다.
- **이력 저장**: 생성된 모든 퀴즈는 SQLite DB에 자동으로 저장됩니다.

## 🛠 기술 스택
- **Backend**: FastAPI, Uvicorn
- **Frontend**: Vanilla JS, Jinja2, Picnic CSS
- **AI**: **CNU AI API** (Mindlogic FactChat Gateway)
- **Scraping**: BeautifulSoup4, Requests
- **Database**: SQLite3

## 🌟 주요 기능 및 UI 시나리오

### 1. 키워드 태그 기반 UI (UI 개선)
- **이전**: 사용자가 키워드를 직접 텍스트로 입력해야 했습니다.
- **현재**: 뉴스 URL 입력 시 기사 본문을 즉시 분석하여 **상위 20개 키워드를 태그 형태로 나열**합니다. 사용자는 나열된 태그 중 원하는 키워드를 클릭하여 퀴즈의 주제를 간편하게 설정할 수 있습니다.

### 2. 시각적 피드백 및 고정 점수판
- **이전**: `alert()` 팝업을 통해 정답 확인이나 점수를 안내했습니다.
- **현재**: 
    - 각 문제 하단에 **✅ 정답** 또는 **❌ 오답** 배지가 즉시 표시됩니다.
    - 정답 선택 시 상세 해설이 하단에 펼쳐집니다.
    - 페이지 최하단에 **점수판(ScoreBoard)**이 고정되어 있어 실시간으로 총점을 확인할 수 있습니다.

## 🛠 기술적 상세 정보

### AI 퀴즈 생성 로직 (**CNU AI API**)
- **엔진**: **CNU AI API**를 활용하여 고성능 인공지능 퀴즈 생성을 수행합니다.
- **프롬프트 엔지니어링**: AI에게 "오직 제공된 뉴스 본문의 사실에만 근거할 것"을 강력히 지시하여 환각(Hallucination) 현상을 방지합니다.
- **데이터 구조**: 생성된 퀴즈는 질문, 4개 선택지, 정답 인덱스, 해설을 포함하는 정형화된 JSON 데이터로 수신됩니다.

### 데이터베이스 및 이력 관리 (SQLite3)
- 생성된 모든 퀴즈 데이터(기사 제목, URL, 생성된 문제들)는 `quiz_history.db`에 저장됩니다.
- 이는 향후 퀴즈 복습 기능이나 데이터 분석용으로 활용될 수 있는 기초 데이터가 됩니다.

### 정밀 크롤링 (Scraping)
- `BeautifulSoup4`를 사용하여 언론사별(에이블뉴스, 네이버 등) 기사 본문 영역 ID를 우선적으로 탐색합니다.
- 정규식을 활용하여 사진 캡션, 기자 이메일, 무단 전재 금지 문구 등 **본문 외 노이즈를 99% 제거**합니다.

## � 사용 예시 (Scenario)

1. **상황**: 사용자가 '장애인 참정권' 관련 뉴스 기사를 학습하고 싶어 합니다.
2. **입력**: 뉴스 URL (`https://www.ablenews.co.kr/...`)을 입력하고 [기사 분석] 실행.
3. **태그 선택**: 추출된 태그 중 '선거권', '장애인' 태그를 클릭.
4. **퀴즈 생성**: 문제 수 3개를 선택하고 [퀴즈 생성] 클릭.
5. **학습**: 
    - AI가 생성한 퀴즈를 풀고 [정답 확인] 클릭.
    - 즉시 나타나는 **✅ 정답 배지**와 **해설**을 보며 오답 노트를 작성.
    - 하단 **"총 3문제 중 2문제를 맞히셨습니다!"** 점수 확인.

## �🚀 시작하기

### 1. 환경 설정
프로젝트 루트 폴더의 `.env` 파일에 API 키가 설정되어 있어야 합니다.
```env
CNU_AI_API_KEY=your_api_key_here
```

### 2. 가상환경 활성화 및 패키지 설치
```bash
# 가상환경 활성화 (macOS)
source ../../.venv/bin/activate

# 필요한 패키지 설치
pip install fastapi uvicorn requests beautifulsoup4 python-dotenv openai
```

### 3. 서버 실행
아래 명령어를 터미널에 입력하여 서버를 실행합니다.
```bash
# lab14/ai-app 디렉토리로 이동 후 실행
cd lab14/ai-app
python main.py
```
서버가 실행되면 브라우저에서 [http://localhost:8000](http://localhost:8000)으로 접속하세요.

### 💡 팁
- 만약 8000번 포트가 이미 사용 중이라는 에러가 발생하면 아래 명령어로 프로세스를 종료 후 다시 시도하세요.
```bash
lsof -ti:8000 | xargs kill -9
```
